## SECTION 5 -- KNOWN BUGS

| # | Severity | Location | Issue |
|---|----------|----------|-------|
| 1 | Low | Cut 5 -- Model Fitter | Gas model CV(RMSE) threshold set to 25 (line ~2960: `const threshold = currentModel==='electric' ? 20 : 25`). ASHRAE G14 monthly threshold is 15% for CV(RMSE) on monthly whole-facility models, not 25%. The 25% threshold is for hourly data. This may mislead students about gas model acceptability. |
| 2 | Low | Cut 5 -- 5P model form | When switching from 3PC to 5P on electric, the upper change-point slider max is 72F but the 5P model can produce physically implausible shapes if the lower CP is set very close to the upper CP. The code constrains `ucp = lcp + 6` but does not prevent the upper slider from being manually dragged below this. |
| 3 | Low | Cut 5 -- Month labels on scatter plot | Single-letter month labels (first character only, e.g., "J" for Jan/Jun/Jul) are ambiguous. Three months start with "J", two with "M", making it impossible to identify individual points. |

If the student previously selected 5P as the electric model form in Cut 5, the residual chart will not reflect that choice. The chart always uses 3PC for electric. |

## SECTION 6 -- PEDAGOGY INTEGRITY

**LANGUAGE -- "measure the savings" / "measured savings"**

No violations found. The prototype consistently uses "inferred savings," "avoided energy use," and "model-predicted baseline" throughout. Cut 7 Panel A explicitly states: "The difference between predicted and actual is the inferred savings -- not measured, inferred." Cut 5 deeper-dive states: "The inverse model doesn't measure savings -- it infers them."

**COUNTERFACTUAL FRAMING -- Baseline model applied to reporting-period OAT**

Correctly implemented. Cut 7 applies the baseline regression model to reporting-period OAT values to generate the counterfactual. The code (populateCut7Table function) fits the model to baseline data and then calls predict3PC/predict3P with reporting-period OAT values. The callout states: "The baseline model is applied to reporting-period conditions -- not copied from the baseline period." No tables use raw observed baseline values as the savings reference.

**IPMVP LANGUAGE -- Option A/B/C/D references**

No violations found in prototype.html or handouts.html. Previous audit (2026-04-02) identified 6 violations; all have been fixed. The only remaining reference is the pedagogical rejection in the Cut 2 deeper-dive book quote: "Option letters (A/B/C/D) are not the answer. The physics of the ECM is the answer." This is acceptable -- it explicitly rejects the legacy framing.
